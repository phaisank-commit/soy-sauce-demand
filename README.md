# Soy Sauce Demand Lab — เว็บไซต์แบบจำลองอุปสงค์ซอสถั่วเหลืองช่วงเทศกาลกินเจ

**สาขาวิชาเศรษฐศาสตร์เกษตรและธุรกิจเกษตร (AB) • คณะเกษตรศาสตร์ มทร.ศรีวิชัย ไสใหญ่**

## ไฟล์ในชุดเว็บไซต์

- `index.html` — เว็บไซต์ Interactive ใช้บนมือถือ คอมพิวเตอร์ และแท็บเล็ต
- `qr-offline.js` — โมดูลสร้าง QR Code ในเบราว์เซอร์โดยไม่ส่งลิงก์ไปบริการภายนอก (MIT License; original Kazuhiko Arase QRCode)
- `.nojekyll` — ช่วยเผยแพร่เว็บไซต์ไฟล์ static บน GitHub Pages
- `README.md` — คู่มือไฟล์นี้

## เปิดใช้งานทันที

1. แตกไฟล์ ZIP
2. เปิด `index.html` ใน Chrome, Edge หรือ Safari (QR สำหรับแชร์ยังต้องมี URL จริง)
3. ปรับแถบข้อมูล ลองสถานการณ์ต่ำ/ฐาน/สูง และกด **ดาวน์โหลด CSV**

## เผยแพร่ให้เด็กเข้าผ่านลิงก์ (GitHub Pages)

1. เข้าสู่ [github.com](https://github.com/) แล้วสร้างบัญชีฟรีหากยังไม่มี
2. กด **New repository** แล้วตั้งชื่อ `soy-sauce-demand` และเลือก **Public**
3. เข้า repository → **Add file → Upload files** → อัปโหลด `index.html`, `qr-offline.js`, `.nojekyll` และ `README.md` (ต้องนำไฟล์จาก ZIP ออกก่อน อัปโหลด ZIP อย่างเดียวไม่ทำงาน)
4. กด **Commit changes**
5. เข้า **Settings → Pages → Build and deployment → Source: Deploy from a branch**
6. เลือก branch `main` และ folder `/(root)` แล้วกด **Save**
7. เมื่อ GitHub แจ้งลิงก์แล้ว เปิด URL จากหน้า **Settings → Pages** ตัวอย่าง `https://YOUR_USERNAME.github.io/soy-sauce-demand/` โดย **เปลี่ยน YOUR_USERNAME เป็นชื่อบัญชีจริง**
8. ทดลองเปิดบนโทรศัพท์หรือเครื่องนักศึกษาที่ไม่ได้เข้าสู่บัญชี GitHub

คู่มืออย่างเป็นทางการ: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

> หมายเหตุ: ต้องเผยแพร่ไฟล์ทั้ง `index.html` และ `qr-offline.js` ในโฟลเดอร์เดียวกัน เว็บไซต์สาธารณะทุกคนที่มีลิงก์สามารถเข้าถึงได้ และไม่ควรใส่ข้อมูลส่วนบุคคล/ข้อมูลลับ

## สร้าง QR Code สำหรับห้องเรียน

1. หลังเว็บเผยแพร่ เปิดเว็บไซต์ของคุณผ่าน URL `https://...`
2. เลื่อนลงไปที่หัวข้อ **ลิงก์และ QR Code ให้นักศึกษา** ซึ่งสร้าง QR จาก URL หน้าเว็บอัตโนมัติ
3. หากใช้ URL อื่น วาง URL แล้วกด **สร้าง QR**
4. กด **บันทึก PNG** เพื่อได้ภาพ QR พร้อมนำไปใส่สไลด์ เพจ Facebook หรือโปสเตอร์
5. **ทดลองสแกน QR ด้วยมือถือจริง** ตรวจสอบว่าเปิดเว็บได้ก่อนแจกนักศึกษา

## วิธีใช้สำหรับการสอน

- ให้นักศึกษาเลือกสถานการณ์ฐาน จากนั้นระบุว่าข้อมูลใดเป็น “สมมติฐาน”
- เปรียบเทียบอุปสงค์รวมกับอุปสงค์ส่วนเพิ่มจากอัตราใช้ปกติ
- ลองเปลี่ยนผู้ร่วมกินเจ, จำนวนวัน, ปริมาณใช้ต่อคน และราคา เพื่ออธิบายความอ่อนไหว
- ดาวน์โหลดไฟล์ CSV และแสดงวิธีคำนวณจากสูตรที่อยู่บนเว็บ
- ย้ำว่า “มูลค่าความต้องการสมมติ” ไม่ใช่ยอดขายจริงหรือกำไร และส่วนแบ่งตลาดไม่ใช่หลักฐานการขาย

## วิธีคำนวณ

`ผู้ใช้ซอส (คน) = ผู้กินเจ × สัดส่วนใช้ซอส / 100`

`ปริมาณช่วงเทศกาล (ลิตร) = ผู้ใช้ซอส × ปริมาณช่วงเทศกาล (มล./คน/วัน) × วัน / 1,000`

`ส่วนเพิ่มสุทธิ (ลิตร) = ผู้ใช้ซอส × [มล.ช่วงเทศกาล − มล.ภาวะปกติ] × วัน / 1,000`

`มูลค่าการใช้ (บาท) = ปริมาณรวม (ลิตร) × ราคาเฉลี่ย (บาท/ลิตร)`

**ค่าตั้งต้นเป็นสมมติฐานเพื่อการศึกษา:** ผู้กินเจ 20 ล้านคน, ใช้ซอส 75%, ช่วงเทศกาล 10 มล./วัน, ปกติ 6 มล./วัน, 9 วัน, 70 บาท/ลิตร, ส่วนแบ่งตัวอย่าง 1%, ขวด 700 มล. มิใช่ตัวเลขจากงานสำรวจปี 2569

**เทศกาลกินเจ 2569:** 10–18 ตุลาคม = 9 วัน; อาจนับเป็น 10 วันเมื่อรวมวันล้างท้อง 9 ตุลาคม อ้างอิง https://lib.nbtc.go.th/news/detail/2805
